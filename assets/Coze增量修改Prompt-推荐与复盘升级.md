# Coze增量修改Prompt：推荐股票与复盘升级

请基于当前「A股可视化投研Agent」小程序版本继续升级，不要推翻现有页面结构和视觉风格。本次只做增量修改，重点解决以下功能：

1. 增加「今日行情自动推荐股票」功能。
2. 推荐股票可以一键填入「开始研究」模块。
3. 修改「正方研究员/反方研究员」命名，避免用户误解。
4. 复盘页增加机器学习曲线拟合与预测/实际走势对比。
5. 首次进入小程序时，先做投资风格导向问卷。

## 1. 首次进入：投资风格导向问卷

用户第一次打开小程序时，不要直接进入市场页，先弹出一个轻量问卷，用来判断用户适合短线、波段还是长期风格。

问卷标题：

```text
先了解你的投资风格
```

问卷说明：

```text
我会根据你的风险承受能力、持有周期和研究习惯，自动推荐默认投研风格。之后你仍然可以在研究页手动切换。
```

问题建议：

1. 你通常能接受的持有周期是？
- 1到10个交易日
- 2周到3个月
- 6个月以上

2. 如果一只股票短期下跌，你最多能接受多少回撤？
- 5%以内
- 10%以内
- 20%以上

3. 你更关注什么？
- 短期热点和资金流
- 行业趋势和波段机会
- 公司长期价值和财务质量

4. 你每天愿意花多少时间看市场？
- 30分钟以内
- 30分钟到2小时
- 不固定，更关注长期跟踪

5. 你的投资经验是？
- 新手
- 有一定经验
- 比较熟悉市场

问卷结果规则：

- 如果用户更多选择短周期、低回撤、热点资金流，则推荐「短线风格」。
- 如果用户更多选择中等周期、行业趋势、波段机会，则推荐「波段风格」。
- 如果用户更多选择长期周期、公司价值、财务质量，则推荐「长期风格」。

问卷结果页展示：

```text
你的默认投研风格：波段
适合原因：你更关注行业趋势和中期机会，同时能接受一定波动。
默认研究周期：20个交易日
```

要求：

- 将问卷结果保存到「我的」页面。
- 研究页默认选中用户问卷推荐的风格。
- 用户可以随时重新测评。

## 2. 市场页新增：今日AI推荐股票

在市场页「个股异动榜」下方新增一个模块：

```text
今日AI推荐研究标的
```

注意：模块名不要叫「今日推荐买入」，要叫「推荐研究标的」或「今日值得研究」，避免变成荐股。

该模块根据今日行情自动生成3到5只候选股票，每只股票展示：

- 股票名称
- 股票代码
- 所属行业/概念
- 推荐研究风格：短线/波段/长期
- 机会评分
- 风险等级
- 推荐理由
- 主要风险
- 触发来源：板块热度/资金流/公告事件/技术突破/基本面改善
- 按钮：填入研究

示例卡片：

```text
北方华创 002371
推荐风格：波段
机会评分：82
风险等级：中
推荐理由：半导体板块热度提升，资金流入增强，技术趋势保持强势。
主要风险：估值偏高，板块短期拥挤度上升。
[填入研究]
```

生成逻辑：

今日推荐股票不能只按涨幅排行选，要用多因子综合筛选。

筛选因子：

- 板块热度：20%
- 个股涨跌强度：15%
- 成交量/换手率变化：15%
- 资金流向：20%
- 新闻公告催化：10%
- 技术趋势：10%
- 风险惩罚：10%

推荐结果必须包含风险，不得只展示机会。

如果没有真实数据接口，可以先使用Mock数据，但必须标注：

```text
Demo数据，仅用于产品演示，不代表实时行情。
```

## 3. 推荐股票一键填入研究页

在「今日AI推荐研究标的」每张卡片上增加按钮：

```text
填入研究
```

点击后执行：

1. 自动跳转到「研究」Tab。
2. 将股票名称和代码填入「股票/板块」输入框。
3. 自动选中该股票卡片推荐的投资风格。
4. 自动设置默认研究周期：
   - 短线：5日
   - 波段：20日
   - 长期：12个月
5. 在输入框下方显示来源提示：

```text
已从今日AI推荐研究标的填入：北方华创 002371
```

6. 用户仍然需要点击「开始研究」，不要自动开始，避免用户误触。

## 4. 修改Agent角色命名

当前页面中「正方研究员」和「反方研究员」容易让用户误解，尤其「正方」可能被误读为「方正」。请统一改名：

- 「正方研究员」改为「看多研究员」
- 「反方研究员」改为「看空研究员」

英文小字同步修改：

- Bull Agent 改为 Bull Analyst
- Bear Agent 改为 Bear Analyst

页面展示建议：

```text
看多研究员
寻找上涨驱动

看空研究员
寻找风险反证
```

在研究结论中不要写「正方/反方辩论」，改成：

```text
多空观点对比
```

## 5. 复盘页升级：机器学习曲线拟合

复盘页当前只有方向准确率、区间命中率和历史研究列表，需要增加一个更强的可视化模块：

```text
预测曲线拟合
```

该模块用于展示：

- Agent当时预测的价格中位线
- 乐观情景上沿
- 悲观情景下沿
- 实际价格曲线
- 机器学习拟合曲线
- 预测误差曲线

图表要求：

- 使用折线图 + 区间带。
- X轴为日期。
- Y轴为价格或收益率。
- 实际价格使用深色实线。
- Agent预测中位线使用蓝色虚线。
- 乐观/悲观区间使用浅蓝色阴影带。
- 机器学习拟合曲线使用橙色线。
- 误差可以在下方小图展示。

机器学习方法第一版建议：

不要做过度复杂的黑盒模型。使用可解释的轻量方法：

1. 历史收益率滚动均值
2. 历史波动率
3. 多因子评分
4. 市场指数收益
5. 行业指数收益
6. 新闻情绪分数

用这些特征生成拟合曲线。

如果当前无法接入真实机器学习训练，可以先用Mock方式模拟，但前端和数据结构必须按真实机器学习结果设计。

模型名称建议：

```text
LightGBM拟合模型（演示版）
```

或：

```text
多因子回归拟合模型（演示版）
```

为了比赛演示，建议展示为：

```text
模型使用历史价格、波动率、市场指数、行业指数、因子评分和新闻情绪生成拟合曲线，用于复盘Agent预测与实际走势的偏差。
```

复盘指标增加：

- 方向准确率
- 区间命中率
- MAE：平均绝对误差
- RMSE：均方根误差
- 最大回撤
- 最大正偏离
- 最大负偏离
- 相对沪深300收益
- 相对行业指数收益
- 拟合优度R²

展示文案：

```text
本次复盘显示，实际价格大部分时间位于预测区间内，区间命中率为72%。机器学习拟合曲线与实际走势方向基本一致，但在第8个交易日后低估了上涨斜率，说明模型对资金加速流入的反应不足。
```

## 8. 最终验收标准

本次修改完成后必须满足：

1. 用户第一次进入会看到风格导向问卷。
2. 问卷完成后会生成默认投资风格。
3. 市场页有「今日AI推荐研究标的」模块。
4. 推荐股票卡片能一键填入研究页。
5. 填入后股票名称、代码、风格、周期都正确带过去。
6. 页面中不再出现「正方研究员/反方研究员」，改为「看多研究员/看空研究员」。
7. 研究结论中使用「多空观点对比」，不要使用「正反方辩论」。
8. 复盘页有「预测曲线拟合」模块。
9. 曲线图同时展示实际价格、预测中位线、预测区间、机器学习拟合线和误差。
10. 复盘指标包含MAE、RMSE和R²。
11. 所有推荐股票必须写明风险，不能只写机会。
12. 所有结论必须保留免责声明：以上内容仅供研究参考，不构成投资建议。
