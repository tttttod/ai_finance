# Coze增量修改Prompt：tradeTI交易人格测试

请基于当前「A股可视化投研Agent」继续修改首次进入流程。本次核心目标是：把原来的严肃投资风格问卷升级成一个带传播感、搞笑感、SBTI风格的交易人格测试。

测试名称：

```text
tradeTI
```

全称可以写：

```text
Trade Type Indicator
```

中文解释：

```text
交易抽象人格测试
```

## 1. 产品逻辑

用户第一次进入小程序时，不再直接进入市场页，也不再使用普通投资风格问卷，而是先进入「tradeTI交易抽象人格测试」。

测试结束后生成一个交易人格。

重要规则：

- 只有测出「华尔街在逃交易员」的用户，才能进入完整功能区。
- 如果测出其他人格，进入对应的搞笑拦截页。
- 搞笑拦截页只给两个按钮，不能进入正式投研功能。
- 拦截页必须保留「返回重测」入口。
- 这是娱乐化测试，但结果会影响用户后续体验。

## 5. 判定规则

基础规则：

- 每选择一个选项，对应人格 +1分。
- 测试结束后，得分最高的人格为最终人格。
- 如果多个最高分并列，按优先级判定：
  1. 我是秦始皇，打钱！
  2. 梭哈战神
  3. 利好已出尽还在冲
  4. 回本就卖宗师
  5. K线萨满
  6. 蒙特卡洛诗人
  7. 财报考古学家
  8. 老钱，老了才有钱
  9. 华尔街在逃交易员

特殊规则：

- 只有「华尔街在逃交易员」得分达到8分及以上，才判定为「华尔街在逃交易员」。
- 如果「华尔街在逃交易员」得分最高但低于8分，则不要给它通关，改判为第二高人格。
- 如果「我是秦始皇，打钱！」得分达到4分及以上，优先判定为「我是秦始皇，打钱！」。
- 如果「梭哈战神」得分达到4分及以上，优先判定为「梭哈战神」，除非「我是秦始皇，打钱！」也达到4分。

## 11. 合规与语气边界

这是搞笑测试，但必须保留合规边界：

- 不得承诺收益。
- 不得暗示通过测试就一定会赚钱。
- 不得引导真实下载外部软件。
- 「下载反诈APP」「卸载炒股软件」只是页面内的搞笑按钮，不要真的跳转下载。
- 按钮点击后可以弹出一句文案，例如：

```text
冷静是你今天最好的交易。
```

所有页面底部保留：

```text
tradeTI仅供娱乐和投资行为自省，不构成投资建议。股票市场存在风险。
```
