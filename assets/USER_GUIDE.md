## 2. 评委快速体验路径

建议评委按以下路径体验核心闭环：

1. 打开作品访问 URL。
2. 完成 `tradeTI` 交易人格测试，进入主界面。
3. 阅读首次弹出的游戏化新手引导。
4. 在“冒险”页点击“查看玩法指引”，确认教程可以重复打开。
5. 点击“金融华尔界”地图入口。
6. 体验第 1 关“开户日”，完成剧情选择并解锁 Lead Agent。
7. 返回主界面，查看 Agent 研究天团中 Lead Agent 是否点亮。
8. 点击已解锁 Agent，查看人物立绘、展示动画和能力介绍。
9. 继续体验第 2 关“数据黑市”和第 3 关“市场风暴”，理解数据校验与市场环境判断玩法。
10. 进入“任务”页，输入股票或板块，体验 Agent 投研分析链路。
11. 进入“工坊”页，查看通用股票预测模型与因子分析。
12. 进入“档案”页，查看交易人格、关注列表、历史记录和重测入口。

如需重新触发新手引导，可点击页面中的“查看玩法指引”按钮。若部署版本支持强制引导参数，也可以访问：

## 3. 产品简介

**金融华尔界**是一款交易员成长游戏。玩家通过 `tradeTI` 交易人格测试进入游戏，在地图关卡中学习金融知识、修正交易误区，并逐步解锁 12 位投研 Agent。所有 Agent 解锁后，会组成一条完整的投研分析链路，帮助用户从“凭感觉交易”走向“按流程研究”。

本产品用于金融学习、投研训练和信息整理，不提供自动交易服务，所有内容不构成投资建议。

## 6. 第一次使用

1. 打开应用。
2. 完成 `tradeTI` 交易人格测试。
3. 进入主界面后阅读新手引导弹窗。
4. 点击“开始冒险”或进入“冒险”页。
5. 打开“金融华尔界”地图，从第 1 关开始挑战。

玩家的核心目标不是直接获得股票答案，而是补完自己的投研团队：

1. 通过关卡。
2. 解锁 Agent。
3. 点亮研究天团。
4. 使用 Agent 完成股票或板块研究。
5. 形成结论、风险检查和复盘计划。

## 8. 新手引导

首次进入主界面时，系统会弹出游戏化入职邀请函，说明当前产品的玩法：

- 进入金融华尔界地图；
- 完成关卡试炼；

- 逐步补完整套投研链路。

如果后续忘记玩法，可以点击页面上的“查看玩法指引”按钮，重新打开新手引导。

## 9. tradeTI 交易人格测试

`tradeTI` 是进入游戏前的交易人格测试。它会通过一组选择题判断用户常见的交易行为倾向，例如：

- 是否容易追涨；
- 是否过度保守；
- 是否迷信 K 线；
- 是否喜欢直接要代码；
- 是否缺少止盈止损；
- 是否过度依赖模型。

测试结果会影响新手引导中的角色称呼和个性化提示。用户可以在“档案”页重新测试。

## 10. 金融华尔界地图

## 12. 剧情关卡说明

### 12.1 开户日

玩家在废弃交易大厅遇到前明星基金经理顾明澈。他曾因过度自信失去团队，如今成为失意的 Lead Agent。玩家需要帮助他重新确认研究的第一原则：先问问题，再找答案。

通关重点：

- 不急着下单；
- 不盲信热点；
- 先确认研究对象、周期、假设和风险。

### 12.2 数据黑市

玩家进入地下交易厅，面对三张看似矛盾的行情图。Data Agent 要求玩家检查公司记录、更新时间和数据缺口，从错误行情中找出可信数据。

通关重点：

- 数据来源比图表刺激程度更重要；
- 更新时间必须完整；
- 缺失数据会制造假信号。

### 12.3 市场风暴

市场暴跌日，Lead Agent 看到一只逆势较强的股票，准备加仓。Market Agent 要求玩家使用市场观察仪，把视角从个股拉远到行业，再拉远到全市场，并通过三天观察计划控制仓位。

通关重点：

- 个股强弱不能脱离市场环境；
- 逆势表现是信息，但不是无脑加仓理由；
- 市场风暴中优先控制仓位。

## 13. Agent 研究天团

Agent 是玩家逐步解锁的投研队友。每位 Agent 负责一个研究环节：

| Agent | 职责 |
|---|---|
| Lead Agent | 确认研究问题、拆解任务、统筹流程 |
| Data Agent | 检查数据来源、时间戳和缺失项 |
| Market Agent | 判断市场环境和整体风险偏好 |
| Industry Agent | 分析行业趋势、政策和产业逻辑 |
| Fundamental Agent | 分析公司财务、盈利质量和基本面 |
| Valuation Agent | 判断估值区间和安全边际 |
| Technical Agent | 分析技术面、趋势和资金节奏 |
| Sentiment Agent | 判断新闻、公告和舆论情绪 |
| Bull Analyst | 提出看多逻辑和增长故事 |
| Bear Analyst | 提出反证、风险和看空逻辑 |
| Risk Officer | 检查估值、流动性、财务和仓位风险 |
| Research Manager | 汇总争议，生成结论和复盘计划 |

已解锁 Agent 会在研究天团中点亮。点击已解锁 Agent，可以播放人物展示动画，并查看角色立绘和能力说明。

## 14. 发起一次研究

在“任务”页，用户可以输入股票或板块，启动 Agent 投研流程。

基本步骤：

1. 输入研究标的。
2. 选择投资风格和研究周期。
3. 点击开始研究。
4. 系统按 Agent 链路逐步生成分析。
5. 查看多因子评分、多空观点、风险检查、三情景预测和最终结论。

研究结果适合用于训练自己的分析框架，而不是直接作为买卖指令。

## 15. Agent 投研链路

完整链路包含 16 个步骤：

| 步骤 | 内容 | 负责 Agent |
|---|---|---|
| 1 | 确认研究问题 | Lead |
| 2 | 确认投资风格和周期 | Lead |
| 3 | 数据收集与缺失检查 | Data |
| 4 | 市场环境分析 | Market |
| 5 | 行业与政策分析 | Industry |
| 6 | 公司基本面分析 | Fundamental |
| 7 | 估值分析 | Valuation |
| 8 | 技术与资金分析 | Technical |
| 9 | 新闻公告与情绪分析 | Sentiment |
| 10 | 多因子评分 | Lead |
| 11 | 看多观点 | Bull |
| 12 | 看空观点 | Bear |
| 13 | 风险官检查 | Risk |
| 14 | 三情景预测 | Lead |
| 15 | 最终结论 | Research Manager |
| 16 | 复盘任务生成 | Research Manager |

随着地图推进，后续版本可以逐步将未解锁 Agent 对应的能力做成灰显、提示或限制使用。

- 因子库；
- 推荐因子组合；
- 随机股票或指定股票测试；
- 模型评分；
- 方向准确率；
- 区间命中率；
- 误差分析；
- 蒙特卡洛模拟结果。

该模块更适合理解模型如何工作，不适合单独作为交易依据。

## 18. 档案功能

“档案”页用于查看个人状态和历史信息：

- tradeTI 交易人格；
- 关注股票列表；
- 历史研究记录；
- 重新测试入口；
- 风险提示和免责声明。

如果用户希望重新开始人格测试，可以在档案页触发重测。

## 19. 进度保存

产品会在浏览器本地保存部分进度，包括：

- 已完成关卡；
- 已解锁 Agent；
- 失败记录；
- 炒币奖励；
- 已学习卡片；
- 已答对题目；
- 关注列表；
- tradeTI 测试结果。

当前主要使用 `localStorage` 保存，因此同一浏览器可以保留进度。清空浏览器缓存或更换设备后，进度可能丢失。

## 20. 常见问题

### Q1：这个产品会直接推荐股票吗？

产品会展示研究标的和分析结果，但定位是研究辅助和学习训练，不是荐股软件。

### Q2：为什么要先做 tradeTI 测试？

tradeTI 用来识别用户常见的交易误区，让后续新手引导和成长路径更有代入感。

### Q3：为什么要先通关再解锁 Agent？

每个 Agent 代表一个投研能力。通过关卡学习对应能力后，再解锁角色，能让用户理解这个 Agent 在完整链路中的作用。

### Q4：失败后会怎样？

失败不会解锁 Agent。玩家可以重新挑战关卡，直到选择出更合理的研究行为。

### Q5：Agent 解锁后有什么用？

解锁后 Agent 会在研究天团中点亮。后续功能可逐步和 Agent 解锁状态绑定，例如限制特定研究步骤、点亮分析卡片或展示专属角色能力。

### Q6：数据是真实行情吗？

当前版本包含演示数据和部分接口能力。用户应以页面标识为准，不要把演示数据当作实时交易依据。

### Q7：如果评审环境无法登录怎么办？

请优先使用赛事提交材料中提供的测试账号。如果部署版本支持游客体验，可直接进入；如果需要验证码或第三方登录，请在本手册第 1 节补充测试账号、测试权限和测试 Key。

## 21. 风险声明

1. 本产品仅用于金融学习、投研训练和信息整理。
2. 产品中的分析、评分、预测和剧情内容不构成任何投资建议。

5. 产品不承诺收益，不提供自动交易服务。
