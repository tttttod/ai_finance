## 2. 总体设计目标

把当前产品升级成：

```text
未来感金融投研终端 + 小程序交互体验 + 可视化AI Agent工作流
```

不是普通白底卡片页面，也不是纯聊天Bot。

视觉关键词：

- 金融终端
- 智能雷达
- 数据流
- 轻科技感
- 可视化分析
- 卡片化
- 动态反馈
- 专业克制

设计参考方向：

- TDesign MiniProgram 的企业级组件风格
- ECharts for Weixin 的动态图表能力
- 世界地图 effect scatter / 闪光点
- 步骤条、进度条、雷达图、曲线拟合图
- 深色局部模块 + 浅灰主背景

## 3. 全局UI风格要求

请统一全站视觉，不要每个页面风格不一致。

### 3.1 色彩

主背景：

- 使用高级浅灰：#F5F7FA 或 #F6F8FB

深色科技模块：

- 使用深蓝黑：#07111F、#0B1220、#101828

主色：

- 科技蓝：#2563EB 或 #2F6BFF

A股涨跌语义：

- 上涨：红色 #EF233C 或 #F04438
- 下跌：绿色 #12B76A 或 #039855

风险：

- 琥珀色 #F59E0B

中性文字：

- 深色 #101828
- 次级文字 #667085

禁止：

- 大面积彩虹渐变
- 过度霓虹
- 低质赛博朋克风
- 花哨装饰超过信息本身

### 3.2 卡片

卡片风格：

- 圆角不超过8px
- 背景白色或深色
- 边框使用极浅灰
- 阴影要轻
- 保持金融工具感

不要使用：

- 超大圆角
- 一层卡片套一层卡片
- 纯装饰性大色块

### 3.3 动效

动效只服务理解。

需要增加：

- 问卷选项点击时有轻微选中动画。
- 首页全球新闻地图闪光点有pulse动画。
- Agent执行研究时16步工作流逐步点亮。
- 因子分数从0滚动到最终分。
- 图表渐进绘制。
- 新闻卡片从地图下方轻微浮现。
- 风险卡片用轻微强调，不要剧烈闪烁。

## 5. 首页升级：全球新闻雷达

首页必须增加一个未来感最强的模块：


模块效果：

- 地图上有不同国家的闪光点。
- 闪光点代表值得A股投资者关注的新闻。

```text

重要性：高
```

- 查看影响板块

## 11. 模型评分

每只股票展示：

- 模型评分
- MAE
- RMSE
- R²
- 方向是否正确
- 区间是否命中
- 主要误差原因

评分规则：

```text
模型评分 = 方向准确率 * 30 + 区间命中率 * 25 + R² * 25 - 标准化RMSE * 20
```

评分解释：

- 85分以上：拟合较好
- 70到85分：拟合可用
- 60到70分：拟合一般
- 60分以下：拟合较差
