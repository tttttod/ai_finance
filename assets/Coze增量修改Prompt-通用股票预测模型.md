# Coze增量修改Prompt：第三页通用股票预测模型

请基于当前「A股可视化投研Agent」继续升级第三个Tab。当前第三页是「复盘」页面，请将它改造成：

```text
通用股票预测模型
```

这个页面既保留复盘能力，也作为一个可交互的「多因子股票预测模型实验室」。用户可以看到常用量化因子、选择因子、随机抽样股票做拟合测试、查看模型打分、查看蒙特卡洛模拟结果，并把测试结果汇总到页面下方。

## 1. 页面定位

第三页不再只是展示历史复盘统计，而是变成：

```text
通用股票预测模型实验室
```

页面说明：

```text
选择你想使用的量化因子，模型会随机抽取一组A股样本进行拟合测试，并展示预测曲线、拟合评分、蒙特卡洛模拟和样本股票汇总。结果仅用于研究和模型演示，不构成投资建议。
```

注意：

- 不要把它做成荐股页。
- 不要说模型可以保证预测股价。
- 重点展示「模型如何测试」「因子如何影响结果」「拟合效果如何评分」。

## 3. 常用量化因子库

请在页面中展示一个「因子选择区」，用户可以选择或取消选择因子。

默认选中一组通用因子。因子必须尽量可量化。

### 3.1 动量因子

解释：

股票过去一段时间的涨跌趋势。

可量化指标：

- 5日收益率
- 20日收益率
- 60日收益率
- 120日收益率
- 价格相对20日均线偏离率
- 价格相对60日均线偏离率

### 3.2 反转因子

解释：

短期涨太多或跌太多后，可能出现均值回归。

可量化指标：

- 5日涨跌幅极值
- RSI
- KDJ超买超卖
- 价格偏离布林带上轨/下轨

### 3.3 价值因子

解释：

衡量股票估值是否便宜或偏贵。

可量化指标：

- PE
- PB
- PS
- PEG
- 股息率
- PE历史分位
- PB历史分位

### 3.4 质量因子

解释：

衡量公司盈利质量和财务稳健性。

可量化指标：

- ROE
- ROA
- 毛利率
- 净利率
- 经营现金流/净利润
- 资产负债率
- 应收账款周转率

### 3.5 成长因子

解释：

衡量公司收入和利润增长。

可量化指标：

- 营收同比增速
- 净利润同比增速
- 扣非净利润增速
- 未来一致预期净利润增速
- EPS增速

### 3.6 规模因子

解释：

衡量公司市值大小和风格暴露。

可量化指标：

- 总市值
- 流通市值
- 自由流通市值
- 市值分位数

### 3.7 波动率因子

解释：

衡量股票价格波动和风险。

可量化指标：

- 20日年化波动率
- 60日年化波动率
- 最大回撤
- Beta
- 下行波动率

### 3.8 流动性因子

解释：

衡量交易是否活跃，是否容易出现冲击成本。

可量化指标：

- 日均成交额
- 日均换手率
- 量比
- 买卖价差
- Amihud非流动性指标

### 3.9 资金流因子

解释：

衡量主力资金、北向资金或大单资金方向。

可量化指标：

- 主力净流入
- 北向资金净流入
- 大单净流入
- 资金流连续性
- 龙虎榜机构净买入

### 3.10 情绪/事件因子

解释：

衡量新闻、公告、研报和市场舆情影响。

可量化指标：

- 新闻情绪分数
- 公告情绪分数
- 研报评级变化
- 研报目标价变化
- 热搜/舆情热度
- 事件催化强度

### 3.11 行业/市场因子

解释：

衡量个股所在行业和大盘环境。

可量化指标：

- 行业指数20日收益率
- 行业资金流
- 行业估值分位
- 沪深300收益率
- 市场成交额变化
- 上涨家数占比

### 3.12 拥挤度因子

解释：

衡量交易是否过热，是否存在短期拥挤风险。

可量化指标：

- 成交额历史分位
- 换手率历史分位
- 融资余额变化
- 机构持仓集中度
- 涨停/连板热度

## 5. 随机十只股票拟合测试

点击「开始随机拟合测试」后：

1. 随机抽取10只A股样本。
2. 每只股票生成一条拟合测试记录。
3. 模型对每只股票生成：
   - 实际价格曲线
   - 预测中位线
   - 机器学习拟合线
   - 蒙特卡洛模拟区间
   - MAE
   - RMSE
   - R²
   - 方向准确率
   - 区间命中率
   - 模型评分

如果没有真实数据接口，使用Mock数据，但数据不要过于完美。必须让拟合结果稍微杂乱、有误差、有偏离，避免看起来像假图。

Mock数据要求：

- 不要让R²全部超过0.9。
- 10只股票中至少2只拟合较差。
- 至少1只股票方向预测错误。
- 至少2只股票实际价格短暂突破预测区间。
- 蒙特卡洛路径要有随机噪声。
- 每只股票的误差和走势都不同。

模型评分规则：

```text
模型评分 = 方向准确率 * 30 + 区间命中率 * 25 + R² * 25 - 标准化RMSE * 20
```

评分解释：

- 85分以上：拟合较好
- 70到85分：拟合可用
- 60到70分：拟合一般
- 60分以下：拟合较差

## 6. 蒙特卡洛模拟

为每只样本股票增加蒙特卡洛模拟模块。

模拟逻辑：

- 基于历史收益率均值和波动率。
- 生成至少100条未来价格路径。
- 展示P10、P50、P90三条分位线。
- 展示最终价格分布。
- 展示上涨概率、下跌概率、跌破风险线概率。

前端展示：

- 主图：实际价格 + 预测中位线 + ML拟合线 + 蒙特卡洛P10/P50/P90区间。
- 小图：最终收益率分布直方图。

文案示例：

```text
蒙特卡洛模拟基于历史波动率生成100条可能路径。当前样本显示，未来20个交易日上涨概率为58%，跌破风险线概率为22%。该结果用于展示不确定性，不代表确定预测。
```

## 9. 模型总结汇总

在十只股票列表下方增加汇总卡：

```text
本次模型测试总结
```

内容包括：

- 本次使用因子数量
- 样本股票数量
- 平均模型评分
- 平均方向准确率
- 平均区间命中率
- 平均MAE
- 平均RMSE
- 平均R²
- 表现最好的股票
- 表现最差的股票
- 哪些因子贡献最大
- 哪些因子可能造成噪声
- 是否存在过拟合风险

示例文案：

```text
本次随机抽取10只股票进行拟合测试，平均模型评分为74分，方向准确率为70%，区间命中率为63%。动量、资金流和行业强度贡献较高，估值分位在短周期预测中的解释力较弱。两只样本出现明显偏离，说明模型对突发事件和资金加速流入的反应仍不足。
```
