# Bug：信息迷雾岛返回金融华尔界时出现空白页

## 问题描述

目前在「信息迷雾岛」页面中，点击左上角的返回键后，**不能直接返回「金融华尔界」主地图界面**。

当前实际表现是：

```text
金融华尔界
→ 点击「信息迷雾岛」
→ 进入信息迷雾岛
→ 点击左上角返回键
→ 出现空白页 ❌
```

期望行为应该是：

```text
金融华尔界
→ 点击「信息迷雾岛」
→ 进入信息迷雾岛
→ 点击左上角返回键
→ 直接回到金融华尔界主地图 ✅
```

## 请重点排查

请不要通过“再加一个返回按钮”来绕过这个问题，而是检查当前页面/组件的导航状态是否有问题。

重点检查以下几类可能原因：

1. 「信息迷雾岛」进入时，是通过什么状态或路由打开的。
2. 左上角返回键当前执行的具体逻辑是什么，例如：
   - `router.back()`
   - `window.history.back()`
   - `setActiveXXX(null)`
   - 修改某个 `activeMap / activeLocation / activeGameLevel`
   - 页面条件渲染状态切换
3. 返回后是否只关闭了「信息迷雾岛」组件，但**没有把“金融华尔界主地图”重新设为当前激活页面**，从而导致所有条件分支都不满足，最终渲染成空白页。
4. 是否存在类似下面这种状态组合：
   - `activeSubmap = null`
   - 但 `showWorldMap = false`
   - 或 `activeLocation = null`
   - 同时主地图组件又因为其他状态没有被渲染
5. 如果信息迷雾岛本质上是金融华尔界里的二级地图/子地图，请不要依赖浏览器 history 返回，而应该明确执行：
   - 关闭当前子地图
   - 清除当前子地图/地点状态
   - 恢复金融华尔界主地图状态

## 正确的交互逻辑

请统一成：

```text
金融华尔界主地图
        ↓
点击信息迷雾岛
        ↓
信息迷雾岛子地图
        ↓
点击左上角返回
        ↓
金融华尔界主地图
```

也就是说，「信息迷雾岛」左上角返回键的 parent 应该明确是：

```text
金融华尔界（World Map）
```

而不是一个中间空状态，也不是浏览器历史中的未知页面。

## 修改要求

请先找到导致空白页的真实原因，再做最小修改。

不要修改：

- `WORLD_LOCATIONS` 中其他地点的功能
- `TRADER_PATH` 主线顺序
- 华尔堡及其二级地图逻辑
- Agent 解锁逻辑
- 其他小游戏
- 用户进度存储逻辑

如果项目里已经存在统一的 `handleBackToWorldMap`、`handleLocationClick`、`activeSubmap`、`activeLocationId` 或类似机制，请优先复用，不要再创建一套重复导航状态。

## 还需要顺便检查

请检查所有从「金融华尔界」进入的二级地图/地点是否存在同样的问题。

尤其确认：

```text
金融华尔界 → 华尔堡 → 返回 → 金融华尔界
金融华尔界 → 信息迷雾岛 → 返回 → 金融华尔界
```

这两个流程的返回逻辑应该尽量共用同一套方法，避免一个能正常返回、另一个返回空白页。

## 验收标准

修复后需要满足：

1. 从金融华尔界点击「信息迷雾岛」能够正常进入。
2. 在信息迷雾岛点击左上角返回键，只需点击一次。
3. 点击后立即回到金融华尔界主地图。
4. 中间不能出现空白页。
5. 返回后主地图原来的状态仍然存在，不应刷新成异常初始状态。
6. 再次点击信息迷雾岛仍然可以正常进入。
7. 不影响华尔堡以及其他地图地点的点击和返回逻辑。

请先排查并告诉我**具体是哪一个 state / router / 条件渲染分支导致空白页**，再修改代码，不要直接大范围重构。
