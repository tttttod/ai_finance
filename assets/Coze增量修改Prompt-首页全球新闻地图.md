# Coze增量修改Prompt：首页全球新闻雷达地图

请基于当前「A股可视化投研Agent」继续升级首页。本次新增一个首页模块：

```text
全球新闻雷达地图
```

该模块用于展示全球范围内值得A股投资者关注的宏观、政策、产业、地缘、商品和科技新闻。地图上用会动的闪光点标记不同国家/地区的重要新闻。用户点击某个闪光点后，对应国家/地区高亮，新闻卡片浮现，并用文字解释这条海外新闻可能影响哪些A股板块。

## 1. 模块位置

请将「全球新闻雷达地图」放在首页「今日市场AI摘要」下方、「指数卡片」上方或「板块热度榜」上方。

首页推荐顺序：

1. 今日市场AI摘要
2. 全球新闻雷达地图
3. 指数卡片
4. 今日AI推荐研究标的
5. 板块热度榜
6. 个股异动榜

## 2. 模块标题和说明

标题：

```text
全球新闻雷达
```

副标题：

```text
追踪全球宏观、政策、科技、商品与地缘事件对A股的潜在影响
```

如果使用Demo数据，请显示：

```text
Demo数据，仅用于产品演示，不代表实时新闻。
```

## 3. 地图视觉要求

请在首页卡片中展示一个世界地图。

视觉风格：

- 背景使用深色或低饱和蓝灰色，像金融终端的全球雷达。
- 国家轮廓使用细线，不要过度花哨。
- 新闻发生地用闪光点标记。
- 闪光点需要有轻微脉冲动画。
- 闪光点颜色按事件类型区分：
  - 红色：风险/地缘/监管冲击
  - 蓝色：科技/AI/半导体
  - 橙色：能源/大宗商品/通胀
  - 绿色：经济改善/贸易利好
  - 紫色：央行/利率/汇率
- 闪光点大小按重要性变化：
  - 重要性高：大点 + 强脉冲
  - 重要性中：中点
  - 重要性低：小点

点击某个国家或闪光点后：

- 对应国家/地区区域高亮。
- 闪光点放大。
- 地图旁边或下方浮现新闻卡片。
- 其他国家闪光点变暗。
- 新闻卡片可以轻微上浮出现。

## 4. 交互要求

用户可以：

- 点击地图上的闪光点。
- 点击国家/地区新闻列表。
- 左右切换不同新闻。
- 点击「查看影响板块」。
- 点击「加入今日研究线索」。

点击美国闪光点示例：

1. 美国区域高亮。
2. 美国闪光点放大并持续脉冲。
3. 新闻卡片浮现：

```text
美国 | AI芯片出口管制新规
影响类型：科技/半导体/政策
重要性：高
新闻摘要：美国拟进一步收紧部分AI芯片出口规则，市场关注国产替代链条。
可能影响A股：半导体设备、AI芯片、国产算力、先进封装
影响方向：短期情绪偏积极，但需关注政策不确定性
```

点击「查看影响板块」后展示：

- 半导体
- AI算力
- 先进封装
- 服务器
- 国产软件

点击「加入今日研究线索」后：

- 将该新闻加入首页「今日研究线索」列表。
- 在研究页可以从线索进入相关板块或股票研究。

## 5. 新闻分类

每条全球新闻必须标记事件类型。

事件类型包括：

- 宏观经济
- 央行利率
- 汇率
- 地缘政治
- 能源商品
- AI科技
- 半导体
- 新能源
- 医药监管
- 贸易政策
- 供应链
- 消费需求

每条新闻还需要标记：

- 国家/地区
- 经纬度或地图坐标
- 新闻标题
- 新闻摘要
- 事件时间
- 重要性：高/中/低
- 情绪方向：positive/negative/neutral/mixed
- 影响A股板块
- 影响逻辑
- 风险提示

## 9. 技术实现建议

如果当前工具支持地图组件：

- 使用世界地图GeoJSON或轻量SVG世界地图。
- 使用坐标映射将经纬度转换为地图点位。
- 闪光点使用CSS动画实现pulse效果。
- 选中国家时添加高亮class。
- 新闻卡片使用浮层或底部抽屉。

如果当前工具不支持完整地图：

- 使用简化SVG世界地图或静态世界地图背景。
- 在固定百分比坐标上放置闪光点。
- 保证交互体验优先，不必追求地理边界完全精准。

移动端要求：

- 地图卡片高度建议260到320px。
- 新闻卡片不要遮挡整个地图。
- 点击点位后，新闻卡片从下方浮现。
- 列表项也可以触发地图高亮，避免小屏点位难点。

4. 点击美国闪光点后，美国区域或美国点位明显高亮。
5. 点击后浮现美国新闻卡片。
6. 新闻卡片展示新闻摘要、事件类型、重要性、影响A股板块、影响逻辑和风险提示。
7. 地图下方有今日全球事件列表。
8. 点击列表项也能联动地图高亮。
